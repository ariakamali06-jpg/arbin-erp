# سامانه جامع مالی و حسابداری آربین

نسخه نمایشی رابط کاربری سیستم ERP آربین

## ویژگی‌ها
- رابط کاربری فارسی و RTL
- ماژول‌های دفتر کل، خزانه، انبار، فاکتور، حقوق
- طراحی مدرن با فونت وزیرمتن

## یادداشت
این نسخه دمو فقط رابط کاربری را نمایش می‌دهد. برای نسخه کامل با backend به [ریپو اصلی](https://github.com/ariakamali06-jpg/arbin-erp) مراجعه کنید.
