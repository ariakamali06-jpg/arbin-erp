# پلتفرم حسابداری هوشمند آربین (Arbin Core Engine)

موتور حسابداری مالی دوبل و ابری بر پایه استانداردهای مالی و مالیاتی ایران — جایگزین مدرن، چابک و امن برای نرم‌افزارهای سنتی مانند سپیدار.

## ساختار ماژول‌ها و فایل‌ها

```text
arbin/
├── api.py               # وب‌سرویس RESTful بر پایه FastAPI + سرو SPA (static/)
├── database.py          # اتصال SQLite، مایگریشن اسکیما، تبدیل تقویم جلالی
├── ledger.py            # هسته سندزن دوبل: کدینگ حسابها، ترازنامه، بستن سال مالی
├── reports.py           # تراز آزمایشی ۴ ستونی، سود و زیان، ترازنامه، گردش حساب
├── treasury.py          # خزانه: چرخه چک صیادی، تراکنش‌های رسید/پرداخت، POS، راس‌گیری
├── inventory.py         # انبار: رسید/حواله/برگشت/مغایرت، میانگین موزون، کاردکس
├── invoicing.py         # فروش: فاکتور رسمی، مالیات بر ارزش افزوده ۱۰٪، سامانه مؤدیان
├── payroll.py           # حقوق: بیمه ۷٪/۲۳٪، مالیات پلکانی ماده ۸۴، فیش و سند خودکار
├── ai_copilot.py        # هوش مالی: خواندن فاکتور، پیش‌بینی کسری نقدینگی، صوت به سند
├── seed_data.py         # کدینگ استاندارد حسابداری ایران (گروه/کل/معین) + داده نمایشی
├── schema.sql           # ساختار دیتابیس، قوانین دوبل، وضعیت اسناد و چک‌ها
├── static/
│   ├── index.html       # SPA راست‌چین ۶ بخش: داشبورد، دفتر کل، خزانه، انبار، فروش، حقوق
│   ├── app.js           # وضعیت کلاینت، تعامل API، مودال‌ها، روتینگ تب‌ها
│   └── styles.css       # تایپوگرافی و استایل RTL اختصاصی
└── tests/               # مجموعه تست pytest برای ۵ ماژول + AI (۷ تست)
```

## راه‌اندازی

```bash
# ۱) نصب وابستگی‌ها (offline-capable)
pip install fastapi uvicorn pydantic httpx pytest

# ۲) اجرای سرور
uvicorn api:app --host 0.0.0.0 --port 8000

# ۳) راه‌اندازی داده نمایشی + کدینگ استاندارد (از UI یا API)
curl -X POST http://localhost:8000/api/v1/bootstrap -H "Content-Type: application/json" -d '{}'

# ۴) باز کردن رابط کاربری
#    http://localhost:8000/static/index.html
```

## نحوه اجرای تست‌ها

```bash
pytest tests -q
# 7 passed
```

- `tests/test_ledger.py` — تراز سند، تراز آزمایشی، قید/حذف اسناد، بستن سال مالی و افتتاحیه
- `tests/test_treasury.py` — چرخه چهار مرحله‌ای چک (دریافت → وصول → پاس/برگشت) و ترازنامه
- `tests/test_inventory.py` — میانگین موزون، بهای تمام‌شده، برگشت فروش، مغایرت، کاردکس
- `tests/test_invoicing.py` — جمع فاکتور، مالیات ۱۰٪، شناسه یکتای ۲۲ رقمی (Verhoeff)، ابطال
- `tests/test_payroll.py` — بیمه ۷٪/۲۳٪، معافیت و پله‌های ماده ۸۴، سند دوبل حقوق
- `tests/test_ai_copilot.py` — استخراج فاکتور، پیش‌بینی کسری نقدینگی، تبدیل متن به سند

## قابلیت‌های برتر نسبت به سپیدار سیستم

| قابلیت | سپیدار سیستم | پلتفرم آربین (Arbin) |
|---|---|---|
| **نوع معماری** | دسکتاپی (Windows-Only)، نیازمند RDP | ۱۰۰٪ ابری (Cloud-Native)، کار در مرورگر و موبایل |
| **قفل نرم‌افزاری** | دانگل فیزیکی USB با هزینه تعویض و ریسک سوختن | قفل دیجیتال امن با رمزنگاری مدرن |
| **تضمین توازن سند** | اعتبارسنجی در لایه نرم‌افزار دسکتاپ | اعتبارسنجی ریاضی در لایه هسته و دیتابیس (ACID) |
| **اتصال به سیستم‌های دیگر** | وب‌سرویس اختصاصی گران‌قیمت (۴۰+ میلیون تومان) | Open API استاندارد و وب‌هوک‌های لحظه‌ای |
| **ردپای حسابرسی (Audit)** | لاگ‌های متنی پراکنده و قابل دستکاری | لاگ تغییرات زنجیره‌ای و غیرقابل جعل (Append-Only) |
| **کدینگ پیش‌فرض** | نیازمند تنظیمات پیچیده | تزریق خودکار کدینگ استاندارد ایران با یک کلیک |
| **حقوق و دستمزد** | ماژول گران‌قیمت جداگانه (۳۵+ میلیون تومان) | هسته خودکار بیمه ۳۰٪، مالیات پله‌ای و دیسکت پایا |
| **هوش مصنوعی مالی (AI Copilot)** | فاقد هرگونه هوش مصنوعی (صفر درصد) | فاکتورخوان هوشمند، پیش‌بینی کسری چک و تبدیل صوت به سند |
